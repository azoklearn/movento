# Paradiso — Real Estate Newsletter CTA

Create a responsive hero section for a website containing an email subscription form. It must be perfectly responsive for mobile and tablet devices.

Here are the specific requirements:

1.  **Structure & Layout:**
    *   The section should have a fixed height of exactly 550px.
    *   The content should be centered within a rounded, card-like container.
    *   Include a background video using this URL: https://cdn.sceneai.art/Hero Section Video/adec243d-ffda-48cf-a8a8-26e6d6bcbe9b.mp4
    *   Add a dark overlay over the video to ensure text readability.

2.  **Typography & Content:**
    *   **Main Text:** "Be the first to know <br> about nearby homes."
        *   Style: Medium font weight, tighter line-height, text size relatively smaller.
        *   Layout: Break into two lines, with the first line ending after the word "know".
    *   **Secondary Text:** "Enjoy seamless moving experiences with trusted <br> professionals by your side every step."
        *   Style: 15px font size, regular font weight.
        *   Layout: Break into two lines, with the first line ending after the word "trusted".
    *   **Input Field:** Placeholder text should be "Enter your email address" with regular font weight.
    *   **Subscribe Button:** Text "Subscribe", button color must be solid black.

3.  **Animations:**
    *   When the page loads, all content must appear smoothly, step-by-step.
    *   The main heading specifically must animate appearing word-by-word with a staggered delay.

Please provide only one single HTML file containing all HTML, Tailwind CSS, and JavaScript required to render this exactly as described without any extra content.

RESPONSIVE (required): the site must be fully responsive — it has to display and work correctly on mobile, tablet and desktop, with no horizontal scrolling at any screen width.
